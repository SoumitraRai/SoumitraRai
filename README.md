## How I build AI products

- **The model reads and reasons; code does the rest.** Maths, access control, and anything that must give the same answer twice run in plain code, outside the LLM.
- **Evidence over confidence.** An answer cites where it came from, or it refuses and says why.
- **Production plumbing included.** Idempotent webhooks, job queues, PostgreSQL, Docker, and deploys on GCP and AWS.
